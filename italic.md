# Italic

↑ **Parent:** [Macro](macro.md)


```
Some \i[italic] text.
```
which renders as:



> Some _italic_ text.

The insane shorthand `*italic*` is equivalent to `\i[italic]`, with the same delimiter rules as [bold](bold.md).


```
Some *italic* text.
```
which renders as:



> Some _italic_ text.

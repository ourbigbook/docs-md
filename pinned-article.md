# Pinned article

↑ **Parent:** [OurBigBook Admin](ourbigbook-admin.md)

[OurBigBook Admins](ourbigbook-admin.md) can select one article from any user to be pinned to the website's "front index pages" such as the global article, [topics](ourbigbook-web-topics.md) or user indexes.

The typical use case of this feature is to facilitate user onboarding, and it could also be used for general server announcemnets.

To modify the pinned article, admins must visit the [site settings page](site-settings-page.md).

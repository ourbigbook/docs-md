<h1 id="dry-run-push"><code>--dry-run-push</code></h1>

↑ **Parent:** [`--dry-run`](dry-run.md)

Similar to [`--dry-run`](dry-run.md), but it runs all git commands except for `git push`, which gives a clearer idea of what `--publish` would actually do including the git operations, but without publishing anything:
```
./ourbigbook --dry-run --publish .
```

<h1 id="china"><code>--china</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

This is the most important option of the software.

It produces a copy of the HTML of [https://cirosantilli.com/china-dictatorship](https://cirosantilli.com/china-dictatorship) to stdout.

The data is stored inside an NPM package, making it hard to censor that information, see also: [https://cirosantilli.com/china-dictatorship#mirrors](https://cirosantilli.com/china-dictatorship#mirrors)

Usage:
```
ourbigbook --china > china.html
firefox china.html
```

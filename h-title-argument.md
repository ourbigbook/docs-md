# `\H` `title` argument

↑ **Parent:** [`\H` arguments](h-arguments.md)  
🏷️ **Tags:** [`title` argument](title-argument.md)

Contains the main content of the header. The [shorthand syntax](macro-shorthand-syntax.md):
```
= My title
```
is equivalent to the sane:
```
\H[1][My title]
```
and in both cases `My title` is the title argument.

The [`title` argument](title-argument.md) is also notably used for [automatic ID from title](automatic-id-from-title.md).

# `description` argument

↑ **Parent:** [Pseudo-macro argument property](pseudo-macro-argument-property.md)

The [`description` argument](description-argument.md) is similar to the [`title` argument](title-argument.md) in that it adds information about some block such as an [image](image.md) or [code block](code-block.md). The difference from the title is that it does not count toward [automatic ID from title](automatic-id-from-title.md) calculations.

<h1 id="web-cancel-build"><code>--web-cancel-build</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Request cancellation of the authenticated user's current build without converting or uploading. Implies [`-W`, `--web`](web.md). Cancellation is saved on the server and continues even if the CLI exits; an in-flight article or tree transaction may finish first. Completed articles are preserved. The build owner and administrators can also use the red Cancel build button below pagination in that user's Build jobs settings; it appears only while a build is ongoing.

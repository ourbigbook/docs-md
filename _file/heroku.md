<h1 id="_file/heroku">heroku</h1>

↑ **Parent:** [Heroku deployment](../heroku-deployment.md)

The [heroku](heroku) helper allows us to omit the boring `-a ourbigbook`, e.g. we can just type:
```
./heroku logs -f
```
instead of:
```
./heroku logs -a ourbigbook -f
```

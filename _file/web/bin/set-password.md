<h1 id="_file/web/bin/set-password">web/bin/set-password</h1>

↑ **Parent:** [Web CLI utils](../../../web-cli-utils.md)

Change password for a given user. Usage:
```
set-password <username> <new-password>
```
Note that this can also be achieved on the web interface by visiting the settings page of a target user with an [OurBigBook Admin](../../../ourbigbook-admin.md) account.

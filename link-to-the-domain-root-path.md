# Link to the domain root path

↑ **Parent:** [`\a` `external` argument](a-external-argument.md)

The [`\a` `external` argument](a-external-argument.md) can be used to refer to the root of the domain. E.g. suppose that we have a [subdirectory deployment](subdirectory-deployment.md) under `https://mydomain.com/subdir/`. Then:
- `\a[/somepath]` refers to the directory `/subdir/somepath`
- `\a[/somepath]{external}` refers to the directory `/somepath`

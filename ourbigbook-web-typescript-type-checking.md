# OurBigBook Web TypeScript type checking

↑ **Parent:** [OurBigBook Web static analysis](ourbigbook-web-static-analysis.md)

TypeScript type checking of [OurBigBook Web](ourbigbook-web.md) is run automatically during build, e.g. by:
```
npm run build-dev
```
as mentioned at [local optimized frontend](local-optimized-frontend.md).

To speed up the development loop further, you can run just the TypeScript type checking with:
```
cd web
nmp run typecheck
```
The output format is also a bit nicer that what is shown in `npm run build-dev`.

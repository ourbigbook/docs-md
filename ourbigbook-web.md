# OurBigBook Web

↑ **Parent:** [OurBigBook Project](split.md)

OurBigBook Web is the software program that powers [https://OurBigBook.com](https://OurBigBook.com), its official flagship instance, see also: [Section "OurBigBook.com"](ourbigbook-com.md). [OurBigBook Web](ourbigbook-web.md) is currently the main tool developed by the [OurBigBook Project](split.md).

This section contains both [end user documentation](ourbigbook-web-user-manual.md) and [developer documentation](ourbigbook-web-development.md).

More subjective rationale, motivation and planning aspects of the project are documented at: [https://cirosantilli.com/ourbigbook-com](https://cirosantilli.com/ourbigbook-com).

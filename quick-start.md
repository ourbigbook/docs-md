# Quick start

↑ **Parent:** [OurBigBook Project](split.md)

The following sections cover different ways to use tools from the OurBigBook:
- [OurBigBook Web user manual](ourbigbook-web-user-manual.md): manual for [OurBigBook Web](ourbigbook-web.md), the dynamic website. With this approach, you can write content on the browser without downloading anything, and save it on our database.
- convert local `.bigb` files with either:
  - [Visual Studio Code quick start](visual-studio-code-quick-start.md)
  - [OurBigBook CLI quick start](ourbigbook-cli-quick-start.md)

  This method allows you to publish either as:
  - a [static website](p-publish.md)
  - to [OurBigBook Web](ourbigbook-web.md)
- [OurBigBook Markup quick start](ourbigbook-markup-quick-start.md): covers specifically [OurBigBook Markup](ourbigbook-markup.md), which is the markup language you use to write content in OurBigBook, both [OurBigBook Web](ourbigbook-web.md) and [OurBigBook CLI](ourbigbook-cli.md).

  This is currently the only way to write OurBigBook content, but we would really like to add [WYSIWYG](todo/wysiwyg.md) editor support one day!

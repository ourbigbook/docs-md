<h1 id="ourbigbook-com-policies">OurBigBook.com policies</h1>

↑ **Parent:** [OurBigBook.com](ourbigbook-com.md)

This session describes policies specific to the OurBigBook.com instance of [OurBigBook Web](ourbigbook-web.md).

Documentation present under [OurBigBook Web user manual](ourbigbook-web-user-manual.md) describes [OurBigBook Web](ourbigbook-web.md) in general.

These policies only applies to the official reference [https://OurBigBook.com](https://OurBigBook.com) instance. If you host your own [OurBigBook Web](ourbigbook-web.md), there are no constraints imposed on your content, only on the source code as per [LICENSE.txt](LICENSE.txt).

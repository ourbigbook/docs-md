# Mandatory positional arguments

↑ **Parent:** [Positional argument](positional-argument.md)

Some positional arguments are required, and if not given OurBigBook reports an error and does not render the node.

This is for example the `level` of a [header](header.md).

These arguments marked with the `mandatory: true` [`--help-macros`](help-macros.md) argument property.

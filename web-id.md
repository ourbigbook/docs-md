<h1 id="web-id"><code>--web-id</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Upload only the selected ID with [`-W`, `--web`](web.md).

That ID must belong to a file being converted for everything to work well. e.g.:
```
ourbigbook --web --web-id quantum-mechanics physics.bigb
```

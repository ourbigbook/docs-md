# Publish your content

↑ **Parent:** [OurBigBook CLI](ourbigbook-cli.md)

There are two ways to publish your [OurBigBook](split.md) content:
- as a [static website](p-publish.md). This means that you generate HTML files from [OurBigBook Markup](ourbigbook-markup.md) files and then publish them either by:
  - uploading to a static website server such as [GitHub Pages](publish-target-github-pages.md) by using the [publish](publish-your-content.md) option
  - converting with [`--publish-target local`](publish-target-local.md) and sending a zip with the pages to someone to view locally
- to an [OurBigBook Web](ourbigbook-web.md) instance such as [OurBigBook.com](ourbigbook-com.md). This can be done either by:
  - editing on the [OurBigBook Web editor](ourbigbook-web-editor.md) directly in your browser
  - uploading [OurBigBook Markup](ourbigbook-markup.md) files from your computer with the [`-W`, `--web`](web.md) option
A fundamental design choice of the [OurBigBook Project](split.md) is that, except for bugs, a single [OurBigBook Markup](ourbigbook-markup.md) source tree can be published in both of those ways without any changes.

The trade-offs between the two options are highlighted at: [OurBigBook Web vs static website publishing](ourbigbook-web-vs-static-website-publishing.md).

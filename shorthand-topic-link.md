# Shorthand topic link

↑ **Parent:** [`\x` `topic` argument](x-topic-argument.md)  
🏷️ **Tags:** [Shorthand macro syntax](macro-shorthand-syntax.md)

If an [shorthand magic link](shorthand-magic-link.md) starts with a hash sign (`#`), then it is converted to a [topic link](x-topic-argument.md) instead of a [magic link](x-magic-argument.md).

For example:
```
<#Albert Einstein>
```
which renders as:



> [Albert Einstein](https://ourbigbook.com/go/topic/albert-einstein)

is equivalent to:
```
\x[Albert Einstein]{topic}
```

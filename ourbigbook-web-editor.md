# OurBigBook Web editor

↑ **Parent:** [OurBigBook Web user manual](ourbigbook-web-user-manual.md)  
🏷️ **Tags:** [Publish your content](publish-your-content.md)

[OurBigBook Web](ourbigbook-web.md) comes with a browser text editor where users can create and edit their articles in [OurBigBook Markup](ourbigbook-markup.md).

This is for example the editor you see when creating a new article at: [https://ourbigbook.com/go/new](https://ourbigbook.com/go/new)

One day want to add an option to have a visual editor: [Section "WYSIWYG"](todo/wysiwyg.md), but for now we'll try to make the text-editor as awesome as we can.

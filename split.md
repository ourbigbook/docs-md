# OurBigBook Project

**[https://OurBigBook.com](https://OurBigBook.com)**: the best way to publish your scientific knowledge.

The **OurBigBook Project** is creating the ultimate [open source](https://github.com/ourbigbook/ourbigbook) tools to [publish](publish-your-content.md) **textbooks**/**[personal knowledge bases](https://ourbigbook.com/go/topic/personal-knowledge-bases)**/**[Zettelkasten](https://ourbigbook.com/go/topic/zettelkasten)**/**[digital gardens](https://ourbigbook.com/go/topic/digital-gardens)** in the [learn in public](https://ourbigbook.com/go/topic/learn-in-public) philosophy. It is our best shot yet at the final **real-world [Encyclopedia Galactica](https://ourbigbook.com/go/topic/encyclopedia-galactica)** by allowing effective **[mind melding](https://ourbigbook.com/go/topic/mindmeld)**/**[collective intelligence](https://ourbigbook.com/go/topic/collective-intelligence)** via the **[topics feature](ourbigbook-web-topics.md)**.

This is the [OurBigBook CLI quick start](ourbigbook-cli-quick-start.md) using our [template project](generate.md) [https://github.com/ourbigbook/template](https://github.com/ourbigbook/template). After [installing Node.js](https://nodejs.org/en/download), run:
```
git clone https://github.com/ourbigbook/template
cd template
npm install
npx ourbigbook .
firefox _out/html/index.html
firefox _out/html/not-index.html
```
This HTML output is also visible at: [https://ourbigbook.github.io/template](https://ourbigbook.github.io/template) Tested on [Linux, MacOS and Windows](ourbigbook-cli-test-matrix.md).

To [publish your project as a static website to GitHub Pages](publish-your-content.md), first create a GitHub repository for it, e.g. `johnsmith/mybrain` and then:
```
git remote set-url origin git@github.com:ourbigbook/ourbigbook-private.git
ourbigbook --publish
```
and your project is now published to [https://johnsmith.github.io/template](https://johnsmith.github.io/template)

To publish your project to [https://OurBigBook.com](https://OurBigBook.com), create an account at [https://ourbigbook.com/go/register](https://ourbigbook.com/go/register) and then:
```
ourbigbook --web
```
This will ask for your ourbigbook username and password, and then your project will be published at: [https://ourbigbook.com/johnsmith](https://ourbigbook.com/johnsmith).

A full blown showcase knowledge base can be seen at:
- [https://cirosantilli.com](https://cirosantilli.com) ([static website](p-publish.md) publish)
- [https://ourbigbook.com/cirosantilli](https://ourbigbook.com/cirosantilli) (equivalent on [OurBigBook.com](ourbigbook-com.md) with dynamic website features such as [topics](ourbigbook-web-topics.md))
- [https://github.com/cirosantilli/cirosantilli.github.io](https://github.com/cirosantilli/cirosantilli.github.io) (source code for both of the above)

**Mission**: to live in a world where you can learn university-level [mathematics](https://ourbigbook.com/go/topic/mathematics), [physics](https://ourbigbook.com/go/topic/physics), [chemistry](https://ourbigbook.com/go/topic/chemistry), [biology](https://ourbigbook.com/go/topic/biology) and [engineering](https://ourbigbook.com/go/topic/engineering) from perfect free open source books that anyone can write to get famous.

**Ultimate goal**: destroy the currently grossly inefficient education system and replace it with a much more inspiring system where people learn what they want as fast as possible to reach their goals faster without so much useless pain.

**How to get there**: [create a website](ourbigbook-web.md) (live at **[https://OurBigBook.com](https://OurBigBook.com)**) that incentivizes learners (notably university students taking courses) to write freely licensed university-level natural science books in their own words for free. Their motivation for doing that are:
- getting their knowledge globally recognized and thus better jobs
- improving the world
- learning by teaching

This makes your articles easier for others to find.

   - **to [OurBigBook.com](ourbigbook-com.md)**: to get awesome multi-user features like [OurBigBook Web topics](ourbigbook-web-topics.md)

   This way you can be sure that even if [OurBigBook.com](ourbigbook-com.md) were to go down one day (which we have no plans to as it is quite cheap to host!), your content will still be perfectly readable as a static site.

1. <a id="image-internal-cross-file-internal-link-intro"></a>
   <img src="https://raw.githubusercontent.com/ourbigbook/ourbigbook-media/master/feature/x/hilbert-space-arrow.png" alt="" height="571">

   **[Figure 7](#image-internal-cross-file-internal-link-intro). Internal cross file internal link**. [OurBigBook](split.md) supports [internal links](internal-link.md) to clean IDs that don't depend on either:
   - source code file paths
   - [table of contents](table-of-contents.md) tree position
   For example, in this screenshot, we are able to link simply from the file:
   ```
   quantum-mechanics.bigb
   ```
   with:
   ```
   <Hilbert space>
   ```
   to the [header](header.md):
   ```
   = Hilbert space
   ```
   present in another file:
   ```
   calculus.bigb
   ```
   without specifying:
   - the source code path `calculus.bigb`
   - the full tree position: `Mathematics` \> `Area of mathematic`s \> `Calculus` \> `Hilbert space`
   This means that you can freely change the location of headers or the tree structure and your links will still work.

   [OurBigBook](split.md) also automatically checks for broken links every time you build, so you will never have a broken link again.

   Live output URLs:
   - [https://cirosantilli.com/calculus#hilbert-space](https://cirosantilli.com/calculus#hilbert-space)
   - [https://cirosantilli.com/quantum-mechanics#schrodinger-picture](https://cirosantilli.com/quantum-mechanics#schrodinger-picture)
   - [https://ourbigbook.com/cirosantilli/hilbert-space](https://ourbigbook.com/cirosantilli/hilbert-space)
   - [https://ourbigbook.com/cirosantilli/schrodinger-picture](https://ourbigbook.com/cirosantilli/schrodinger-picture)

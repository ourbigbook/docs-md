<h1 id="web-ask-password"><code>--web-ask-password</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Ask for the password in an interactive terminal in case there was a default password that would have otherwise been chosen.

Currently the only case where this happens is [`--web-test`](web-test.md) which automatically sets a default `--web-password asdf`.

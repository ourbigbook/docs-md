# `adoc` output format

↑ **Parent:** [`-O --output-format <outformat>`](output-format.md)

Outputs AsciiDoc to an `.adoc` file. It supports the same portable common subset as the [`md` output format](md-output-format.md).

For example:
```
ourbigbook -O adoc index.bigb
```

# Overview of files in this repository

↑ **Parent:** [Developing OurBigBook](developing-ourbigbook.md)

Source files:
- [index.js](_file/index.js.md): main [OurBigBook Markup](ourbigbook-markup.md) conversion code
- [ourbigbook](ourbigbook): CLI executable. Is basically just a CLI interface frontend to `convert`
- [test.js](test.js): contains all the Mocha tests, see also: [test system](test-system.md)
- [README.md](README.md): minimal Markdown README until GitHub / NPM support OurBigBook :-)
- [ourbigbook_runtime.js](ourbigbook_runtime.js): [runtime features](runtime-feature.md)
- [main.scss](main.scss) this file simply contains the customized CSS for [https://docs.ourbigbook.com/](https://docs.ourbigbook.com/) and does not get otherwise distributed with OurBigBook, see: [CSS](css.md)

# `title` argument

↑ **Parent:** [Pseudo-macro argument property](pseudo-macro-argument-property.md)

The [`title` argument](title-argument.md) is an argument that gets used in [automatic ID from title](automatic-id-from-title.md) calculation of macro IDs.

The [`title` argument](title-argument.md) currently appears as both [positional arguments](positional-argument.md) and [named arguments](named-argument.md)

Examples:
- [headers](header.md): `= My header` is equivalent to `\H[1][My header]`, and `My header` is the [`title` argument](title-argument.md), which is a [positional argument](positional-argument.md) in this case
- [images](image.md): in `\Image[flower.jpg]{title=My header}` and `My header` is the [`title` argument](title-argument.md), which is a [named argument](named-argument.md) in this case

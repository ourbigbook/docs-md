# `convert` function

↑ **Parent:** [OurBigBook Library](ourbigbook-library.md)

The `convert` JavaScript function of the [OurBigBook Library](ourbigbook-library.md) is the central [OurBigBook Markup](ourbigbook-markup.md) conversion function of the [OurBigBook Project](split.md).

That function converts an input string to various output formats, and has many options.

It is by both [OurBigBook CLI](ourbigbook-cli.md) and [OurBigBook Web](ourbigbook-web.md).

# OurBigBook Web topics

↑ **Parent:** [OurBigBook Web user manual](ourbigbook-web-user-manual.md)

Topics group articles that have the same title by different users. This feature allows you to find the best article for a given topic, and it is one of the key innovations of [OurBigBook Web](ourbigbook-web.md).

Topics are a bit like Twitter hashtags or Quora questions: their goal is to centralize knowledge about a specific subject by different people at a single location.

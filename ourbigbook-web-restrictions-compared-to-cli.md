# OurBigBook Web restrictions compared to CLI

↑ **Parent:** [OurBigBook Web user manual](ourbigbook-web-user-manual.md)

There are currently a few constructs that are legal in [OurBigBook CLI](ourbigbook-cli.md) but forbidden in Web and will lead to upload errors. TODO we should just make those forbidden on CLI by default with a flag to re-enable if users really want to make their source incompatible with web:
- IDs with uppercase characters as per [JavaScript case conversion](javascript-case-conversion.md)

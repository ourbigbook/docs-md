# Visual Studio Code

↑ **Parent:** [Editor support](editor-support.md)

VS Code is currently intended to be the best supported [non-fully-custom OurBigBook editor](todo/wysiwyg.md).

The official OurBigBook extension is published at: [https://marketplace.visualstudio.com/items?itemName=ourbigbook.ourbigbook-vscode](https://marketplace.visualstudio.com/items?itemName=ourbigbook.ourbigbook-vscode) by the publisher account: [https://marketplace.visualstudio.com/publishers/ourbigbook](https://marketplace.visualstudio.com/publishers/ourbigbook).

# Visual Studio Code extension overhaul

↑ **Parent:** [News](../news-split.md)  
🏷️ **Tags:** [Visual Studio Code](../visual-studio-code.md)

We've greatly improved the [Visual Studio Code extension](../visual-studio-code.md) adding support for the most important VS Code language features: Ctrl + T header search, Ctrl + click jump to header, header outline and link autocomplete

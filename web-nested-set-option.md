<h1 id="web-nested-set-option"><code>--web-nested-set</code> (option)</h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Update the [nested set](nested-set.md) index of [OurBigBook Web](ourbigbook-web.md), don't do anything else. Implies [`-W`, `--web`](web.md).

This option was originally introduced to hep testing bulk nested set updates.

# Design goals

↑ **Parent:** [OurBigBook Markup and CLI overview](ourbigbook-markup-and-cli-overview.md)

OurBigBook is designed entirely to allow writing complex professional HTML and PDF scientific books, blogs, articles and encyclopedias.

OurBigBook aims to be the ultimate [LaTeX](latex-output-format.md) "killer", allowing books to be finally published as either HTML or PDF painlessly (LaTeX being only a backend to PDF generation).

It aims to be [more powerful](features.md) and [saner](saner.md) and than Markdown and Asciidoctor.

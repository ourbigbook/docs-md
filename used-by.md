# Used by

↑ **Parent:** [Header metadata section](header-metadata-section.md)

[File pages](h-file-argument.md) have a "Used by" section linking back to articles that link to the file with \\a or embed it with \\Image, \\image or \\Video. Repeated uses in the same article appear only once, and a file page does not link back to itself. This works in static HTML and on the website, including automatically generated file previews. External URLs are not included.

These backlinks use the existing file references (`ARef`), so existing web articles need no backfill or re-extraction. Rebuild static output to display the new section; `ourbigbook . --force-render` also refreshes cached authored file pages.

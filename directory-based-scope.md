# Directory-based `scope`

↑ **Parent:** [`\H` `scope` argument](h-scope-argument.md)

Putting files in subdirectories of the build has the same effect as adding a [scope](h-scope-argument.md) to their top level header.

Notably, all headers inside that directory get the directory prepended to their IDs.

The toplevel directory is determined as described at: [the toplevel index file](the-toplevel-index-file.md).

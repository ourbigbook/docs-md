# Quotation

↑ **Parent:** [Macro](macro.md)  
🏷️ **Tags:** [Block macro](block-macro.md), [Macro with shorthand syntax](macro-with-shorthand-syntax.md)

[Explicit macro](macro-shorthand-syntax.md):


```
And so he said:

\Q[
Something very smart

And with multiple paragraphs.
]

and it was great.
```
which renders as:



> And so he said:
> 
> > Something very smart
> > 
> > And with multiple paragraphs.
> 
> and it was great.

[Implicit syntax](macro-shorthand-syntax.md):


```
And so he said:

> Something very smart

  And with multiple paragraphs.

and it was great.
```
which renders as:



> And so he said:
> 
> > Something very smart
> > 
> > And with multiple paragraphs.
> 
> and it was great.

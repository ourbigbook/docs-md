<h1 id="wiki-explicit-subsection">History of Tiananmen Square</h1>

↑ **Parent:** [`\H` `wiki` argument](h-wiki-argument.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tiananmen_Square#History)

Note that in this case, you either need a [literal argument](literal-arguments.md) `{{}}` or to explicitly escape the `#` character as in:
```
= History of Tiananmen Square
{wiki=Tiananmen_Square\#History}
```
to avoid the creation of an [shorthand topic links with a single word](shorthand-topic-links-with-a-single-word.md).

Also note that Wikipedia subsections are not completely stable, so generally you would rather want to link to a permalink with a full URL as in:
```
= Artificial general intelligence
{wiki=https://en.wikipedia.org/w/index.php?title=Artificial_general_intelligence&oldid=1192191193#Tests_for_human-level_AGI}
```
Note that in this case escaping the `#` is not necessary because it is part of the [shorthand](macro-shorthand-syntax.md) [link](link.md) that starts at `https://`.

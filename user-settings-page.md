# User settings page

↑ **Parent:** [OurBigBook Web page](ourbigbook-web-page.md)

Example: [https://ourbigbook.com/go/settings/barack-obama](https://ourbigbook.com/go/settings/barack-obama)

Contains profile and account settings for each user, including limits such as the maximum number of articles that each user may publish.

This page is only visible to user themselves and [admins](ourbigbook-web-admin.md). The limits can only be modified by [admins](ourbigbook-web-admin.md).

<h1 id="input-format-md"><code>--input-format md</code></h1>

↑ **Parent:** [`-I --input-format <inputformat>`](input-format.md)

OurBigBook has basic support for markdown input.

Markdown is a more insane format and for now has no OurBigBook-specific features, but Codex kind of vibe coded it quickly and we did it for the lols.

For now, you can transparently [include](include.md) standard markdown files such as [not-index-md.md](not-index-md.md) with:
```
\Include[not-index-md]
```
and OurBigBook will integrate it into the current project seamlessly. Live demo:

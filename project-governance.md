# Project governance

↑ **Parent:** [Developing OurBigBook](developing-ourbigbook.md)

The [OurBigBook Project](split.md) currently has a single top level executive, the [OurBigBook Admin](ourbigbook-admin.md), who has ultimate power over the project.

There is currently no legal incorporated entity.

These will likely change if the project ever gets any traction, but for now things are being ran in an informal manner only.

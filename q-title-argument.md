# `\Q` `title` argument

↑ **Parent:** [`\Q` argument](q-argument.md)  
🏷️ **Tags:** [`title` argument](title-argument.md)

See: [Section "`title` argument"](title-argument.md).

Example with [explicit macro](macro-shorthand-syntax.md):


```
See the: <quote Julius Caesar star>.

\Q[The fault, dear Brutus, is not in our stars, but in ourselves.]
{title=Julius Caesar star}
```
which renders as:



> See the: [Quote 3. "Julius Caesar star"](#quote-julius-caesar-star).
> 
> <a id="quote-julius-caesar-star"></a>
> > The fault, dear Brutus, is not in our stars, but in ourselves.

Example with [implicit syntax](macro-shorthand-syntax.md):


```
See the: <quote Julius Caesar star implicit>.

> The fault, dear Brutus, is not in our stars, but in ourselves.
{title=Julius Caesar star implicit}
```
which renders as:



> See the: [Quote 4. "Julius Caesar star implicit"](#quote-julius-caesar-star-implicit).
> 
> <a id="quote-julius-caesar-star-implicit"></a>
> > The fault, dear Brutus, is not in our stars, but in ourselves.

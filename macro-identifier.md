# Macro identifier

↑ **Parent:** [OurBigBook Markup syntax](ourbigbook-markup-syntax.md)

[OurBigBook Markup](ourbigbook-markup.md) macro identifiers can consist of the following letters:
- `a-z` lowercase
- `A-Z` uppercase
- `0-9`
Since underscores `_`  or hyphens `=` are not allowed, [camel case](https://en.wikipedia.org/wiki/Camel_case) macro names are recommended, e.g. for [`\OurBigBookExample`](ourbigbookexample.md) we use the name:
```
OurBigBookExample
```

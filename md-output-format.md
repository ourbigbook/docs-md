# `md` output format

↑ **Parent:** [`-O --output-format <outformat>`](output-format.md)

Outputs Markdown to a `.md` file.

The portable common subset of OurBigBook headers, paragraphs, emphasis, links, images, code, quotes, lists, horizontal rules, mathematics and tables is converted to the closest Markdown construct.

For example:
```
ourbigbook -O md index.bigb
```

Markdown output is generally viewed as a downgrade of data structures, since markdown is a subset of [OurBigBook](split.md). One major use case is to publish directly GitHub, thus treating the markdown as an output entirely.

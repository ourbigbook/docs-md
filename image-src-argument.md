# Image `src` argument

↑ **Parent:** [Image argument](image-argument.md)  
🏷️ **Tags:** [Positional argument](positional-argument.md)

The address of the image, e.g. in:
```
\Image[image.png]
```
the `src` is `image.png`.

Analogous to the [`\a` `href` argument](a-href-argument.md).

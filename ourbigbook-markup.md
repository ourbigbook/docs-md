# OurBigBook Markup

↑ **Parent:** [OurBigBook Project](split.md)

OurBigBook Markup is the [lightweight markup language](https://en.wikipedia.org/wiki/Lightweight_markup_language) used in the [OurBigBook](split.md) project.

It works both on the [OurBigBook Web](ourbigbook-web.md) dynamic website, and on [OurBigBook CLI](ourbigbook-cli.md) static websites from the command line.

[OurBigBook Markup](ourbigbook-markup.md) files use the `.bigb` extension.

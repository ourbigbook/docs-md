# Shorthand magic link

↑ **Parent:** [`\x` `magic` argument](x-magic-argument.md)  
🏷️ **Tags:** [Shorthand macro syntax](macro-shorthand-syntax.md)

A [magic link](x-magic-argument.md) can be created more succinctly by surrounding the link with "angle brackets" (`<>`), e.g.:
```
<Partial derivative>
```
is equivalent to:
```
\x[Partial derivative]{magic}
```

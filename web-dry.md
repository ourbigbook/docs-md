<h1 id="web-dry"><code>--web-dry</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

[`-W`, `--web`](web.md) dry run, skip any operations that would interact with the [OurBigBook Web](ourbigbook-web.md) server, doing only all the local preparation required for upload.

This is mostly useful for testing the [OurBigBook CLI](ourbigbook-cli.md).

# Shorthand link termination character

↑ **Parent:** [Shorthand link parsing rules](shorthand-link-parsing-rules.md)

The following characters are the "shorthand link termination characters":
- space ` `
- newline `\n`
- open or close square bracket `[` or `]`
- open or close curly braces `{` or `}`
[Shorthand internal links](shorthand-internal-link.md) and [shorthand topic links with a single word](shorthand-topic-links-with-a-single-word.md) terminate if any of these characters are found, see also: [Section "Shorthand link parsing rules"](shorthand-link-parsing-rules.md).

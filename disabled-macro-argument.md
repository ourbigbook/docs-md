# Disabled macro argument

↑ **Parent:** [Macro argument property](macro-argument-property.md)

Some macro arguments are disabled by default.

These are typicially arguments which felt like a good idea one day, but which we ended up regretting.

They can be enabled via [`ourbigbook.json`](ourbigbook-json.md) options TODO, but doing so will make the project incompatible with [OurBigBook Web](ourbigbook-web.md), so it is not advised.

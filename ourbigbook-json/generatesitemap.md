<h1 id="ourbigbook-json/generatesitemap"><code>generateSitemap</code></h1>

↑ **Parent:** [`Ourbigbook.json`](../ourbigbook-json.md)

<a id="ourbigbook-json/_3744"></a>
If `true`, generate a [text sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap#text) and place it in the [`_obb` directory](../obb-directory.md) when publishing at path:<a id="ourbigbook-json/_3745"></a>

```
_obb/sitemap.txt
```

<a id="ourbigbook-json/_3746"></a>
This options requires you to also set [`publishRootUrl`](publishrooturl.md).

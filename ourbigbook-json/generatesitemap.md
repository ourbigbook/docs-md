<h1 id="ourbigbook-json/generatesitemap"><code>generateSitemap</code></h1>

↑ **Parent:** [`Ourbigbook.json`](../ourbigbook-json.md)

If `true`, generate a [text sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap#text) and place it in the [`-/obb` directory](../obb-directory.md) when publishing at path:
```
-/obb/sitemap.txt
```

This options requires you to also set [`publishRootUrl`](publishrooturl.md).

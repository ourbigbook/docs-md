<h1 id="ourbigbook-json/template"><code>template</code></h1>

↑ **Parent:** [`Ourbigbook.json`](../ourbigbook-json.md)

Select the template Liquid file to use.

Serves as the default for the [`template`](template.md).

If this option is not given, and if a file [ourbigbook.liquid.html](../ourbigbook-liquid-html.md) exists in the project, then that file is used.

If [ourbigbook.liquid.html](../ourbigbook-liquid-html.md) exists but you don't want to use it, set the option to `null` and it won't be used.

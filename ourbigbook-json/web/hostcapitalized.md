<h1 id="ourbigbook-json/web/hostcapitalized"><code>hostCapitalized</code></h1>

↑ **Parent:** [`Web`](../web.md)

Capitalized version of [`host`](host.md), e.g. `OurBigBook.com`.

Default:
- if [`host`](host.md) is given, use it
- otherwise, `OurBigBook.com`

Shows up on [`linkFromStaticHeaderMetaToWeb`](linkfromstaticheadermetatoweb.md) as a potentially more human readable version of the hostname.

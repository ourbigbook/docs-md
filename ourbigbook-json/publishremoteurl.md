<h1 id="ourbigbook-json/publishremoteurl"><code>publishRemoteUrl</code></h1>

↑ **Parent:** [`Ourbigbook.json`](../ourbigbook-json.md)

<a id="ourbigbook-json/_3921"></a>
A custom `remoteUrl` to upload the publish to, e.g.:<a id="ourbigbook-json/_3922"></a>

```
"publishRemoteUrl": "git@github.com:ourbigbook/ourbigbook.git"
```

<a id="ourbigbook-json/_3923"></a>
If not given this value is extracted by default from the `origin` remote of the Git repository were the source code is located in.

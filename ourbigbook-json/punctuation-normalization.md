<h1 id="ourbigbook-json/punctuation-normalization">Punctuation normalization</h1>

↑ **Parent:** [`Id` `normalize` `punctuation`](id-normalize-punctuation.md)

<a id="ourbigbook-json/_3789"></a>
Some selected punctuation marks are automatically converted into their dominant corresponding pronunciations. These are:<a id="ourbigbook-json/_3790"></a>

<a id="ourbigbook-json/_3791"></a>
- `%`: `percent`
<a id="ourbigbook-json/_3792"></a>
- `&`: `and`
<a id="ourbigbook-json/_3793"></a>
- `+`: `plus`
<a id="ourbigbook-json/_3794"></a>
- `@`: `at`
<a id="ourbigbook-json/_3795"></a>
- `−` (Unicode minus sign, U+2212, distinct from the ASCII hyphen): `minus`

<a id="ourbigbook-json/_3796"></a>
Dashes are added around the signs if needed, e.g.:<a id="ourbigbook-json/_3797"></a>

<a id="ourbigbook-json/_3798"></a>
- `C++`: `c-plus-plus`
<a id="ourbigbook-json/_3799"></a>
- `Q&A`: `q-and-a`
<a id="ourbigbook-json/_3800"></a>
- `Folding@home`: `folding-at-home`

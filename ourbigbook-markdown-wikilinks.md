# OurBigBook Markdown wikilinks

↑ **Parent:** [OurBigBook Markdown shorthand extensions](ourbigbook-markdown-shorthand-extensions.md)

Analogous to Obsidian, generates [internal cross references](internal-link.md):


```
Hello my [[OurBigBook]]!

I like [[headers]].

And here with custom text [[header|fancy headers]].
```
which renders as:



> Hello my [OurBigBook](split.md)!
> 
> I like [headers](header.md).
> 
> And here with custom text [fancy headers](header.md).

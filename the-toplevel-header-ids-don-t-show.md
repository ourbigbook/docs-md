<h1 id="the-toplevel-header-ids-don-t-show">The toplevel header IDs don't show</h1>

↑ **Parent:** [The toplevel header](the-toplevel-header.md)

Header IDs won't show for the toplevel level. For example, the headers would render like:
```
My 2

1. My 3 1

2. My 3 2
```
rather than:
```
1. My 2

1.2. My 3 1

1.2. My 3 2
```
This is because in this case, we guess that the `h2` is the toplevel.

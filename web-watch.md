<h1 id="web-watch"><code>--web-watch</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Only monitor the user's current web build, including staging, until it finishes or fails. Implies [`-W`, `--web`](web.md); performs no local conversion or upload. Use Ctrl-C to stop watching without cancelling the server build.

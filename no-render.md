<h1 id="no-render"><code>--no-render</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Only extract IDs to fill the [ID database](cross-file-internal-link-internals.md), don't render. This saves time if you only want to render a single file which has references to other files without getting any errors.

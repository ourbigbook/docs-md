# Site settings page

↑ **Parent:** [OurBigBook Web page](ourbigbook-web-page.md)

Example: [https://ourbigbook.com/go/site-settings](https://ourbigbook.com/go/site-settings)

The [site settings page](site-settings-page.md) contains global site settings that apply to the entire [OurBigBook Web](ourbigbook-web.md) instance.

Its values can be viewed by all users, but only [admins](ourbigbook-web-admin.md) can modify their values.

The page can be reached via the "Site Settings" button at the bottom of each index page e.g. [https://ourbigbook.com](https://ourbigbook.com).

# OurBigBook Web search

↑ **Parent:** [OurBigBook Web user manual](ourbigbook-web-user-manual.md)

OurBigBook Web supports basic search for [ID](element-id.md) prefixes of articles and [topics](ourbigbook-web-topics.md). Current search limitations:
- only matches the start of IDs, not in the middle words
- cannot both search and sort simultaneously, e.g. sorting by articles with the greates score or newest articles

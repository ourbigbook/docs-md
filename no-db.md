<h1 id="no-db"><code>--no-db</code></h1>

↑ **Parent:** [OurBigBook CLI options](ourbigbook-cli-options.md)

Don't use the [ID database](cross-file-internal-link-internals.md) during this run. This implies that the on-disk database is not read, and also not written to. Instead, a temporary clean in-memory database is used.
